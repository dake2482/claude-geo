# GEO 四层模型(报告叙事主轴)

```
01 被发现(Discover)    抓取入口层  HTTPS·规范域·robots·Sitemap·llms.txt·SSR·导航
02 被理解(Understand)  语义解释层  H 层级·FAQ·Schema·表格化·面包屑·语言标注
03 被信任(Trust)       主体证明层  公司实体·联系方式·案例·作者·权威来源·隐私政策
04 被引用(Cite)        答案资产层  FAQ·教程·对比·案例·流程·可核验定义与数据
```

## 用法

1. **管理层摘要第一句 = 四层定位**:如"瓶颈集中在第一层与第三层"(PalFish)、"发现问题集中在架构与内容层"(入境客)。
2. **GEO 详情章节**按层组织,每层四段:实测 → 判定 → 缺口 → 动作。
3. **数字资产地图**按层分栏:已具备(需保留)/ 缺失(按 GEO 价值排序)。
4. **路线图阶段与层对应**:第一阶段解除发现层阻断 → 第二阶段补理解层结构 → 第三阶段建信任+引用资产。

## 依赖关系(向用户解释优先级时的核心话术)

发现层不通 → 理解/信任/引用的全部投入对 AI 不可见(先修发现);
发现通了但理解层弱 → AI 看得见但读不懂实体(Schema/语义);
理解通了但信任层断 → AI 读得懂但不敢引用(实体/来源/案例);
前三层都通 → 比拼引用资产厚度(问答/定义/对比/流程/案例)。
