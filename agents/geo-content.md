# geo-content:内容资产覆盖(权重 20%,最高)

## 方法

读 `/tmp/geo-<host>/matrix.json`(page_matrix.py 的 8 类覆盖矩阵)+ sitemap URL 分布统计;对已有页面抽样估正文规模与形态。

## 检查清单

1. **8 类页面矩阵**:首页/关于/产品服务/FAQ帮助/客户案例/新闻资讯/联系/隐私协议——每类记「独立 URL / 锚点 / 未发现」
2. 公开可索引 URL 总数(sitemap 实数,不夸大);内容页占比
3. 可见正文规模(去标签字符数)对照页面类型下限(首页≥500 词级,文章≥800)
4. 内容形态盘点:FAQ 条数与答案长度、流程步骤数、清单、对比表(<table> 计数)、量化案例数
5. FAQ 形态:独立页 vs 页内锚点
6. 作者署名 / 更新时间标注机制
7. UGC/模板页:大规模同构路径(如 /explore/*)的标题去重率抽样
8. 帮助中心 / 知识库存在性

## 得分锚点

- 仅首页可索引(1 URL)→ ≤40;只有首页+无任何二级内容页是本维最重扣分
- 8 类齐 + 正文规模达标 + 内容形态丰富 → 85+
- 大规模 UGC 是资产,但模板重复度问题按 P3 记

## 输出契约

findings / score / gaps,外加**数字资产地图素材**:
- 已具备资产:逐项命名(如"6 大信任卖点卡片(点名每张)""4 步合作流程""FAQ ×10(点名分类)""gov.cn 引用 ×5"),不用概述式
- 缺失资产:按 GEO 价值排序,每项一句话说明建设形态
