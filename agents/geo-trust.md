# geo-trust:L3 品牌与产品实体完整度(权重 15%)

回答:**AI 能否建立"这个品牌 = 一个可核验的真实主体"的认知**。E-E-A-T 口径。

## 检查清单

1. 公司法律名称 / 运营主体(正文、页脚、About、Schema 四处找)
2. **NAP 一致性矩阵**:名称/地址/电话/邮箱 在 Meta Description vs 正文 vs JSON-LD vs 页脚 是否一致——旧地址、旧电话、占位符(client@example.com、13900000000)逐一点名
3. 资质/牌照/ICP 备案号存在与可达
4. 关于页深度:团队/创始人/历程/使命(只有一段话 = 弱)
5. 联系页:真实电话/邮箱/工作时间/地址(而非仅表单)
6. 客户案例/用户故事:数量、是否量化、是否有授权说明
7. 作者署名与内容更新时间机制
8. **权威来源引用实测**:页面引用的 gov/官方链接逐个 curl 状态码;量化主张("50,000 名教师")是否有就近来源
9. 隐私政策/服务协议:存在性 + 表单数据是否合规披露;收费业务无隐私政策 = P1
10. 品牌命名统一度(站内是否混用多个品牌名)
11. 免责声明、资料核对日期标注(有的话是加分项)

## 得分锚点

- 无公司主体 + 无联系方式 + 无隐私政策 → ≤35
- 法律主体/联系方式/隐私政策齐 → 70;案例 + 作者机制 + 权威来源实测有效 → 85+

## 输出契约

findings / score / gaps,外加**实体资料表**:一处权威的 NAP 应该长什么样(供整改统一)
